# The MultiPCM's samples: the pcm region (mpr-15551 and mpr-15552, 4 MB) cut into named samples, read by
# tools/pcm_samples.py (assets.json: pcm_samples). Positions and names only: every byte comes from the
# user's own ROM set when the assets are extracted.
#
# 'page P sets S...'    the sound sets whose part template (the sound program's part_templates) puts page P,
#                       the 512 KB from P x 80000, in a window of the chip: screen 1's at 100000, screen 2's
#                       at 180000
# 'OFFSET LENGTH NAME'  a sample: where it is in the pcm region and its length (hex); its WAV is
#                       assets/sound/samples/NAME.wav. A NAME on more than one line: the same bytes at each
#                       place (one WAV for them all)
# 'uses NNN S...'       the sound sets that play header NNN, in a window (and NNN + 100, screen 2's copy)
#
# After '#': the headers that start in the sample, then what plays it: the sound commands ("sound NN", the
# V70's requests), the sound program's tables (a program: instruments[NN]; a drum kit N: drum_kits[N], the
# parts' program F0 + N; the MIDI channel and the notes the songs write) and the game's code that requests
# them. Names come from that use: a drum by its note in the General MIDI map, an instrument by its part in
# the songs (bass; chords: several notes at once; lead; phrase: one note only), in the folder of the first
# song that plays it (radio order: Magical Sound Shower, Passing Breeze, Splash Wave, Picture the Rivers,
# Blow Your Cool, Looking for the Rainbow, Speed King, Adventure, Sonic Control, Last Wave, Jingle Bell; then
# the Mega Radio Station, Mega Driver, Dream Flying, Meaning of the Light, the race's opening, the staff
# credits, sound 0C and the song no sound command starts, which sound set 2 is for). Nobody has listened to
# them: a name says what plays the sample, not what it sounds like; a sound the game was not seen to
# request is named by its sound command (sound_NN).
